# CutReview

Video review with timecoded comments. A client opens a share link and leaves feedback pinned to an exact timecode (optionally drawn on the frame); the editor tracks statuses and exports markers to DaVinci Resolve.

## Tech stack

React 18 · Vite · TypeScript (strict) · React Router (HashRouter) · TanStack Query · Zustand · CSS Modules · Supabase (Postgres + RLS, Auth, Storage, Realtime) · GitHub Pages.

## How to run

```bash
npm install
cp .env.example .env   # leave Supabase vars empty for demo mode
npm run dev
```

Scripts: `npm run build` · `npm run typecheck` · `npm run lint` · `npm test`
